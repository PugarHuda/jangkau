Jangkau (Indonesian for reach) is an AI agent that fixes accessibility problems on a web page, then proves every fix before keeping it. It just did that to the headline above.

A batik shop, before and after Jangkau

Same page, same design. A screen reader user could not tell the product photos apart, the form had no labels, and most of the text was too faint to read. Jangkau fixed all 47 failures in 71 seconds.

Counts are failing elements reported by axe-core, the engine behind most accessibility audits.

It fixes one problem at a time, and checks its own work

Most tools stop at a list of problems. Jangkau keeps going until the list is empty, and never trades one problem for another.

  1. Audit

    Runs axe-core in a real browser and takes a screenshot of the page.

  2. Fix

    Starts with the most severe problem and asks the model for small, exact edits.

  3. Verify

    Audits again and compares the page against four checks.

  4. Keep or roll back

    A fix that passes is kept. One that fails is undone and retried with the reason.

A fix is kept only when

  • the problem it targets actually went down
  • no new problem appeared anywhere else
  • no image, link, button or text was deleted
  • the page still looks like the original
